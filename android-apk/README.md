# GUD FNF Android

First playable Android prototype for the GUD FNF fan game. Landscape mode, four touch lanes, falling notes, score, combo, misses and four training-song selections. This initial build uses synthesized hit feedback and placeholder training charts; original Mid-Fight Masses music, character art and official charts are not integrated yet.

Build with GitHub Actions: open the Build GUD FNF Android APK workflow and download the GUD-FNF-Android-APK artifact after a successful run.
