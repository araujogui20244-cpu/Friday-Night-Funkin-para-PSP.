## Recursos fornecidos no pacote recebido
Os seguintes grupos de arquivos foram fornecidos pelo usuário no arquivo `arquivos 📂.zip`. A listagem identifica os conteúdos, mas não informa necessariamente seus autores originais:
- Músicas e vozes: Gospel, Parish, Worship, Zavodila e Tutorial Remix (arquivos OGG).
- Personagens/sprites: BF, Ruv e Sarvente, incluindo variantes escuras.
- Cenários: Church Light, Church Dark, Church Ruv e Hell Church.
- Interface e arte: menu, logo, setas/notas, ícones, imagens de introdução e fonte VCR.
- Diálogos: textos de Gospel, Parish, Worship e Zavodila.

**Importante:** os autores originais, músicos, artistas, animadores, chart creators e titulares de direitos desses recursos não estão identificados de forma verificável nos metadados disponíveis. Os créditos específicos devem ser completados com os nomes/links fornecidos pelos autores. Não se atribui autoria original desses recursos ao responsável pelo port.

## Tecnologias
- PSPSDK / PSPDEV — toolchain usada para compilar homebrew PSP.
- GitHub Actions — automação de compilação.
- PPSSPP — emulador usado para testar o formato EBOOT.PBP.
